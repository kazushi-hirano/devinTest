# HTML入門クイズアプリ

HTML初心者向けの単一選択式クイズアプリケーションです。純粋なJavaScript（バニラJS）で実装されています。

## 📋 機能

- **3問のHTML基礎問題**: HTML入門者向けの厳選された問題
- **単一選択式**: ラジオボタンによる選択形式
- **リアルタイム進捗表示**: 現在の問題番号を表示
- **正誤判定**: 各回答の正誤を自動判定
- **最終スコア表示**: 正解数と正答率を表示
- **レスポンシブデザイン**: モバイル端末にも対応

## 🚀 使用方法

1. `index.html` をブラウザで開く
2. 各問題の選択肢から1つを選択
3. 「次へ」ボタンをクリックして進む
4. 全問題完了後、結果を確認
5. 「もう一度挑戦」で再開可能
